# libs

`glyph-matrix-sdk-2.0.aar` belongs here and is **not** in version control.

Nothing's Glyph SDK licence forbids redistribution: "not lend, lease, rent, sublicense, sell,
redistribute, or otherwise transfer the Software". Committing it would do exactly that, so the
build fetches it instead.

```bash
tools/fetch_sdk.sh
```

Source: https://github.com/Nothing-Developer-Programme/GlyphMatrix-Developer-Kit

The same licence forbids commercial use without written permission from Nothing, and it binds
whoever fetches the aar. This project's MIT licence covers this project's code only.
